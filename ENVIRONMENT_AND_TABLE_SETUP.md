### How to Test MySQL Connection from Linux VM

**Step 1**: Update `basecamp/.env.local` with your MySQL password:

```bash

nano basecamp/.env.local
```

**Step 2**: Create a test script:

```bash
cat > basecamp/ops/test_mysql_connection.py << 'EOF'
#!/usr/bin/env python3
import mysql.connector
import os
from urllib.parse import urlparse
import sys

db_url = os.environ.get('DATABASE_URL')
if not db_url:
    print("❌ DATABASE_URL not set")
    sys.exit(1)

parsed = urlparse(db_url)
config = {
    'host': parsed.hostname,
    'user': parsed.username,
    'password': parsed.password,
    'database': parsed.path.lstrip('/').split('?')[0],
    'ssl_disabled': False
}

print("🔌 Connecting to MySQL...")
print(f"   Host: {config['host']}")
print(f"   Database: {config['database']}\n")

try:
    conn = mysql.connector.connect(**config)
    cursor = conn.cursor()

    # Get all tables with row counts
    cursor.execute("SHOW TABLES;")
    tables = [row[0] for row in cursor.fetchall()]

    print(f"✅ Connected! Found {len(tables)} tables:\n")
    for table in sorted(tables):
        cursor.execute(f"SELECT COUNT(*) FROM {table};")
        count = cursor.fetchone()[0]
        status = "📊" if count > 0 else "⭕"
        print(f"   {status} {table:30} {count:6} rows")

    cursor.close()
    conn.close()
    print("\n✅ MySQL connection working!")

except Exception as e:
    print(f"❌ Connection failed: {type(e).__name__}: {e}")
    sys.exit(1)
EOF

chmod +x basecamp/ops/test_mysql_connection.py
```

**Step 3**: Run the test:

```bash
source load-env.sh
python3 basecamp/ops/test_mysql_connection.py
```

## 2. New Environment Variable: GMAIL_TRANSACTION_SHEET_ID

### What Changed

I've updated `basecamp/.env.local` to include a new variable:

```bash
# Gmail Transaction Sheet (separate file for Zelle/Venmo transactions)
GMAIL_TRANSACTION_SHEET_ID=your_gmail_sheet_id_here
```

### Why Separate from SPREADSHEET_ID?

- **SPREADSHEET_ID** = Main Membership Master (contains "Main", "Families", "Payment-History", "WebApp-Events" sheets)
- **GMAIL_TRANSACTION_SHEET_ID** = Separate Google Sheet for Gmail transaction feed (generated by Google Apps Script)

### How to Find Your Gmail Sheet ID

The Gmail transactions sheet is likely generated by a Google Apps Script trigger that:
1. Reads emails from Gmail (Zelle/Venmo notifications)
2. Parses amounts and sender info
3. Writes to a Google Sheet

**To find the ID**:

1. Go to **Google Drive** → Search for "Gmail" or "Zelle" or "Venmo"
2. Look for a sheet with name like:
   - "Fetch Gmail data"
   - "Gmail Transactions"
   - "Payment Notifications"
   - "email-to-sheets"
3. Open the sheet → Copy the ID from the URL:
   ```
   docs.google.com/spreadsheets/d/[THIS_IS_THE_ID]/edit
   ```
4. Update `basecamp/.env.local`:
   ```bash
   GMAIL_TRANSACTION_SHEET_ID=1ABC123...XYZ
   ```

### Using GMAIL_TRANSACTION_SHEET_ID in Sync Script

When you create the sync routine for gmail_transactions:

```python
# basecamp/ops/sync_sheets_to_mysql.py

GMAIL_SHEET_ID = os.environ.get('GMAIL_TRANSACTION_SHEET_ID')

# Later, when syncing gmail transactions:
gmail_sheet = sheets_service.spreadsheets().values().get(
    spreadsheetId=GMAIL_SHEET_ID,
    range="Active!A:Z"  # Or whatever tab name
).execute()
```

## 3. Rename payment_events → webapp_events

### Current Situation

The **payment_events** table is too narrow in scope. The "WebApp-Events" sheet actually tracks:

| Event Type | Purpose | Examples |
|-----------|---------|----------|
| **Payment** | Payment proof submissions | User uploads Venmo screenshot |
| **Login** | User authentication | Member logs into portal |
| **Export** | Data exports | Admin exports member list |
| **Config** | Settings changes | Admin updates membership prices |
| **Audit** | Administrative actions | Admin approves/rejects payment |

**Current schema** only handles payments. A rename + schema expansion would fix this.

### Migration Plan

#### Step 1: Create Migration File

Create `web-apps/mmr-webapp/db/mmr_migration_v5.sql`:

```sql
-- ============================================================
-- MMR Database Migration v5.0 — Rename payment_events → webapp_events
-- Generalizes table to handle all WebApp events (not just payments)
-- ============================================================

SET FOREIGN_KEY_CHECKS = 0;
SET NAMES utf8mb4;

-- ============================================================
-- 1. RENAME TABLE payment_events → webapp_events
--    Reflects that this table tracks all WebApp events, not just payments
-- ============================================================

RENAME TABLE payment_events TO webapp_events;

-- ============================================================
-- 2. ADD new column to track event type beyond just "payment"
-- ============================================================

ALTER TABLE webapp_events
    ADD COLUMN IF NOT EXISTS EventCategory VARCHAR(50) DEFAULT 'payment'
    COMMENT 'payment, login, export, config, audit, etc.'
    AFTER EventType;

-- ============================================================
-- 3. UPDATE foreign key constraint
-- ============================================================

ALTER TABLE payments
    DROP FOREIGN KEY fk_payments_event,
    ADD CONSTRAINT fk_payments_event
        FOREIGN KEY (EventID) REFERENCES webapp_events(EventID) ON DELETE SET NULL;

-- ============================================================
-- 4. RENAME indexes for clarity
-- ============================================================

ALTER TABLE webapp_events
    RENAME KEY idx_pe_memberid TO idx_we_memberid,
    RENAME KEY idx_pe_email TO idx_we_email,
    RENAME KEY idx_pe_status TO idx_we_status,
    RENAME KEY idx_pe_timestamp TO idx_we_timestamp,
    RENAME KEY idx_pe_matchedmessageid TO idx_we_matchedmessageid;

-- ============================================================
-- 5. Record migration
-- ============================================================

INSERT INTO schema_migrations (version, description) VALUES
('0005', 'Rename payment_events → webapp_events for event generalization')
ON DUPLICATE KEY UPDATE executed_at = CURRENT_TIMESTAMP;

SET FOREIGN_KEY_CHECKS = 1;
```

#### Step 2: Update TypeScript Types

File: `web-apps/mmr-webapp/types/index.ts`

```typescript
// Before
export interface PaymentEvent {
  EventID: string;
  EventType: string;
  Status: 'pending' | 'approved' | 'rejected';
  // ...
}

// After
export interface WebAppEvent {
  EventID: string;
  EventType: string;
  EventCategory: 'payment' | 'login' | 'export' | 'config' | 'audit';
  Status: 'pending' | 'approved' | 'rejected';
  // ...
}
```

#### Step 3: Update Database Functions

File: `web-apps/mmr-webapp/lib/db/payments.ts` (example)

```typescript
// Before
export async function getPaymentEvents(memberID: string) {
  const query = 'SELECT * FROM payment_events WHERE MemberID = ? AND Status = "pending"';
  // ...
}

// After
export async function getWebAppEvents(memberID: string, category: string = 'payment') {
  const query = 'SELECT * FROM webapp_events WHERE MemberID = ? AND EventCategory = ? AND Status = "pending"';
  // ...
}
```

#### Step 4: Search & Replace in Codebase


#### Step 5: Update Python Sync Script

File: `basecamp/ops/sync_sheets_to_mysql.py`

## Helper Script to Verify Sheet IDs

Create `basecamp/ops/verify_sheets.py`:

```python
#!/usr/bin/env python3
import os
import json
from google.oauth2.service_account import Credentials
from googleapiclient.discovery import build

SCOPES = ['https://www.googleapis.com/auth/spreadsheets.readonly']

# Load credentials
creds_path = os.environ.get('GOOGLE_APPLICATION_CREDENTIALS')
creds = Credentials.from_service_account_file(creds_path, scopes=SCOPES)
sheets = build('sheets', 'v4', credentials=creds)

# Test SPREADSHEET_ID
print("🔍 Checking SPREADSHEET_ID...")
try:
    main_sheet_id = os.environ.get('SPREADSHEET_ID')
    result = sheets.spreadsheets().get(spreadsheetId=main_sheet_id).execute()
    print(f"✅ Main spreadsheet found: {result['properties']['title']}")
    print(f"   Sheets in this spreadsheet:")
    for sheet in result['sheets']:
        print(f"     • {sheet['properties']['title']}")
except Exception as e:
    print(f"❌ Main spreadsheet error: {e}")

# Test GMAIL_TRANSACTION_SHEET_ID
print("\n🔍 Checking GMAIL_TRANSACTION_SHEET_ID...")
try:
    gmail_sheet_id = os.environ.get('GMAIL_TRANSACTION_SHEET_ID')
    if gmail_sheet_id == 'your_gmail_sheet_id_here':
        print("⚠️  GMAIL_TRANSACTION_SHEET_ID not configured (still has placeholder)")
    else:
        result = sheets.spreadsheets().get(spreadsheetId=gmail_sheet_id).execute()
        print(f"✅ Gmail spreadsheet found: {result['properties']['title']}")
        print(f"   Sheets in this spreadsheet:")
        for sheet in result['sheets']:
            print(f"     • {sheet['properties']['title']}")
except Exception as e:
    print(f"❌ Gmail spreadsheet error: {e}")
```

Run it:
```bash
source load-env.sh
python3 basecamp/ops/verify_sheets.py
```
